# 🏦 Bank Management System

A desktop-based **Bank Management System** built using **Java Swing** that provides a user-friendly interface for managing banking operations such as account creation, login authentication, deposits, withdrawals, balance inquiry, and transaction history.

## 🚀 Features

- 🔐 Secure user login and signup functionality
- 👤 Account creation and customer management
- 💰 Deposit and withdrawal operations
- 📊 Balance inquiry and mini statement generation
- 🏦 Persistent data storage using file handling
- 🖥️ Interactive GUI built with Java Swing
- ⚡ Event-driven operations using Java AWT listeners

## 🛠️ Tech Stack

- **Language:** Java
- **GUI Framework:** Java Swing, AWT
- **Concepts Used:** Object-Oriented Programming, File Handling, Event Handling
- **Storage:** Local file-based persistence

## 📂 Project Structure
Bank Management System

├── Account.java # Account details and operations

├── Deposit.java # Deposit transaction handling
├── Withdraw.java # Withdrawal transaction handling
├── Signup.java # New user registration
